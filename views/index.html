How it works

Operational context, made useful.

TrainTrack AI brings together the information already used across its dashboards—without presenting the illustrative 3D scene as a live map.

  1. 01

    Bring in service context

    Schedules and reported disruptions are stored by the application and displayed in the relevant dashboards.

  2. 02

    Request a model estimate

    Passenger inputs are sent through the Node API to the Python prediction service and its CatBoost model.

  3. 03

    Share operational changes

    Controller updates are broadcast to connected dashboards so users can see the latest reported status.
